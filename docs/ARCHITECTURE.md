# Kyro Architecture

## Overview

```
kyro/
├─ crates/wallet-core/        Pure Rust: vault, BIP39/32, derivations, signatures, decoding. No network or file access.
├─ apps/desktop/
│  ├─ src-tauri/              Tauri 2 shell: IPC commands, session + auto-lock, filtered net_fetch, native dialogs
│  └─ src/                    React + strict TypeScript interface (no secrets)
├─ packages/
│  ├─ shared/                 IPC contract types + simulated backend for the browser demo mode
│  ├─ chains/                 ChainAdapter: bitcoin (Esplora), evm (viem, chain registry), solana (@solana/kit)
│  ├─ market/                 CoinGecko: top 250, charts, cache, backoff
│  └─ swap/                   SwapProvider: 0x, Jupiter, LI.FI; best price after Kyro fees (fees.ts); exact approvals
├─ brand/                     Logos and icons (SVG)
└─ docs/                      IPC.md (contract), NETWORK.md, DESIGN.md, ARCHITECTURE.md
```

## Who does what

| Step of a send | Layer |
|---|---|
| Build the unsigned transaction (UTXO, nonce, gas, Solana message) | TypeScript (`packages/chains`), via `net_fetch` |
| Decode what is actually going to be signed | Rust (`wallet-core::decode`) |
| Ask for the password | Interface → Rust (Argon2id re-verification) |
| Final confirmation | Rust → **native system window** with the decoded summary |
| Sign | Rust (`wallet-core::sign`), key derived then erased |
| Broadcast | TypeScript, via `net_fetch` |

TypeScript can therefore be wrong or compromised without being able to divert funds: it never sees a key, and Rust shows the user what is being signed.

## Phases

> **Read this first.** Nothing has yet been launched **in the real Tauri application by a human**, and **no native confirmation window has been clicked**. All real sends were made **without an interface** ("headless") by tests that call the **same Rust functions** as the commands (construction, decoding, live checks, signing, broadcast), over Tor; only the click in the native window and the React screen are absent from these tests. The interface has been walked through in demo mode (simulated backend).

Legend: **✅ (headless)** end to end and tested: real testnet broadcast through Kyro's real Rust path, without an interface · **✅** tested end to end by other means (says how) · **⚠️** code written, not fully tested end to end (says exactly what is missing) · **❌** not done.
