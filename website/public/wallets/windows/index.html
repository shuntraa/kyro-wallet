Install

One command

It downloads the latest release from GitHub, checks its SHA-256 against SHA256SUMS and stops if they differ.

Windows · PowerShell

irm https://kyrowallet.com/install.ps1 | iex

macOS and Linux · Terminal

curl -fsSL https://kyrowallet.com/install.sh | sh

Downloads the latest release from GitHub, checks its SHA-256 against SHA256SUMS, then installs it. The scripts are open source: install.ps1 · install.sh (website/src).

Or the file

Install by hand

  1. Run the one-line command in PowerShell, or download Kyro-windows-x64-setup.exe.
  2. If you used the file, verify its SHA-256 first.
  3. SmartScreen may show “Windows protected your PC”. Click More info, then Run anyway.
  4. One Kyro window installs the app, starts it and closes. Kyro appears in the Start menu.
Kyro-windows-x64-setup.exeKyro-windows-x64.msiSHA256SUMS

Kyro-windows-x64-setup.exe: Recommended, updates itself. Kyro-windows-x64.msi: For managed installs, no self-update.

PowerShell
$ Get-FileHash .\Kyro-windows-x64-setup.exe -Algorithm SHA256
Compare with the line in SHA256SUMS

Notes

Good to know on Windows

SmartScreen

The installers are not code-signed yet, so a browser download triggers the warning. The one-line command and in-app updates do not. What SmartScreen means for Kyro.

.exe or .msi

Prefer the .exe: it is the only Windows package that updates itself. The .msi does not.

Updates

The installed app downloads signed updates over Tor, verifies them and applies them when you close it.

Phrase window

The recovery phrase window is excluded from screenshots and screen sharing on Windows.

Same on every system

The full wallet, everywhere

The Windows build is the same Kyro: 36 blockchains, swaps, Earn, hardware wallets and Tor from the first launch. The interface is in English and French.

  • No account and no analytics.
  • Your recovery phrase stays on your computer, encrypted.
  • Your phrase also restores your wallet on another system.

Questions

Common questions

Is Kyro safe to run if SmartScreen warns me?

The warning means the file is unsigned and has little reputation yet. It says nothing about the code either way. Verify the SHA-256 against SHA256SUMS before you click through.

Does Kyro need administrator rights?

No. The installer works for the current user.

Does Kyro run on 32-bit or ARM Windows?

Kyro publishes a 64-bit x64 build. That is the only Windows build.
