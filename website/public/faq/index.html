Frequently asked questions

Can’t find yours? Ask on GitHub.

The basics

Is Kyro Wallet free?

Yes. Kyro is free to download and use, and open source under GPL-3.0-or-later. Sending, receiving and staking cost only the network fee. Swaps from 0.7%, built into the rate. Fee details.

Is Kyro custodial?

No. Kyro is non-custodial. Your keys are created and encrypted on your computer. There is no account and no server holding your funds, so nobody, including us, can freeze, move or recover them.

Which blockchains does Kyro support?

36 blockchains: Bitcoin, Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Cronos, Mantle, Sonic, Flare, Kaia, Gnosis, HyperEVM, Sei, Conflux, Solana, TRON, Cardano, XRP Ledger, Litecoin, Dogecoin, Bitcoin Cash, Dash, Stellar, NEAR, Sui, Monero, TON, Cosmos Hub, Polkadot, Aptos, Algorand, Kaspa and Zcash. Plus 220+ tokens on them. What works on each one.

Which computers does Kyro run on?

Windows (64-bit), macOS (Apple Silicon and Intel) and Linux (x86_64 AppImage or .deb). Download.

Is there a mobile app?

No. Kyro is a desktop app only. An app in a mobile store using the Kyro name is not ours.

Swaps and staking

How much does a swap cost?

The Kyro fee depends on the value of the swap: 5% for $5 or less, down to 0.7% from $10,000, and 0.9% if the token price is unknown. It is already taken out of the amount you receive. The blockchain charges a separate network fee, which goes to the network. Providers may add their own fee, already included in their quote. Full table.

Can I stake with Kyro?

Yes, on Solana, Cardano and TRON. You delegate from your own accounts; your coins never go to Kyro. Kyro takes no fee on staking. How staking works.

Security

Does Kyro support hardware wallets?

Yes: Ledger and Trezor, including Trezor Safe 7. Supported on Bitcoin, Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Cronos, Mantle, Sonic, Flare, Kaia, Gnosis, HyperEVM, Sei, Conflux, Solana, TRON, Cardano, XRP Ledger, Litecoin, Dogecoin, Bitcoin Cash, Dash, Stellar, NEAR, Sui, TON, Cosmos Hub, Aptos, Algorand and Zcash.

What happens if I lose my recovery phrase?

If you also lose your computer or password, your funds cannot be recovered. Kyro keeps no copy and cannot reset it. Write the phrase on paper, keep it offline, and never type it into a website.

Can I import a recovery phrase from another wallet?

Yes. Kyro accepts standard 12 and 24-word BIP39 recovery phrases.

Does Kyro use Tor?

Yes. Tor is built in and on by default, with a separate circuit per blockchain. If Tor fails, Kyro stops instead of connecting directly. You can also use your own servers.

Does Kyro collect any data?

No personal data. No account, no analytics, no identifiers. Once a week, Kyro anonymously downloads a tiny file from its GitHub release over Tor, so GitHub’s download counter can estimate how many wallets are active; you can turn it off in Settings, Privacy. Every server the app contacts is listed in NETWORK.md. This website sets no cookies; it only reads the public usage counters from GitHub.

Is Kyro open source? Has it been audited?

The full source is on GitHub under GPL-3.0-or-later. An internal security review has been done. No external audit has been published yet.

How do I report a vulnerability?

Privately, through GitHub security advisories. Please do not open a public issue. See the security policy.

Download and install

Where should I download Kyro?

Only from GitHub Releases, or from the links on kyrowallet.com/download, which point there.

How do I verify my download?

Compare the SHA-256 of your file with the matching line in SHA256SUMS.

Get-FileHash .\Kyro-windows-x64-setup.exe -Algorithm SHA256   # Windows
shasum -a 256 Kyro-macos.dmg                                  # macOS
sha256sum -c SHA256SUMS --ignore-missing                      # Linux
Windows says “Windows protected your PC”. What do I do?

That is SmartScreen: the installer is not code-signed yet. Verify the checksum, then click More info and Run anyway. The one-line install command checks the checksum for you and does not trigger this warning.

macOS says Kyro can’t be opened. What do I do?

Right-click Kyro in Applications and choose Open, or go to System Settings › Privacy & Security and click Open Anyway.
