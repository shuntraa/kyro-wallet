Getting started

Three steps, no account

  1. Install

    Download Kyro from GitHub for Windows, macOS or Linux. Check the SHA-256 if you want to be sure.

  2. Create or import

    Make a new 12 or 24-word recovery phrase, or import yours. It is encrypted with your password, on your computer.

  3. Send, swap, stake

    Every transaction opens a system window that shows what you are signing. Nothing is sent until you confirm.

Security

Built so you don’t have to trust us

Kyro is open source. Anyone can read the code and build the app themselves.

  • Keys are encrypted on your device and never leave the Rust core.
  • Every signature needs your password and a confirmation in a system window.
  • Unusual transactions ask for a second confirmation.
  • Traffic goes over Tor. Every server Kyro contacts is listed publicly.

Questions

Short answers

Is Kyro Wallet free?

Yes. Kyro is free to download and use, and open source under GPL-3.0-or-later. Sending, receiving and staking cost only the network fee. Swaps from 0.7%, built into the rate. Fee details.

Is Kyro custodial?

No. Kyro is non-custodial. Your keys are created and encrypted on your computer. There is no account and no server holding your funds, so nobody, including us, can freeze, move or recover them.

Does Kyro support hardware wallets?

Yes: Ledger and Trezor, including Trezor Safe 7. Supported on Bitcoin, Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Cronos, Mantle, Sonic, Flare, Kaia, Gnosis, HyperEVM, Sei, Conflux, Solana, TRON, Cardano, XRP Ledger, Litecoin, Dogecoin, Bitcoin Cash, Dash, Stellar, NEAR, Sui, TON, Cosmos Hub, Aptos, Algorand, Hedera and Zcash.

Is Kyro open source? Has it been audited?

The full source is on GitHub under GPL-3.0-or-later. An internal security review has been done. No external audit has been published yet.
