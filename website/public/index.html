First steps with Kyro

Privacy

Everything goes through Tor

Kyro is a Tor wallet from the first launch. Balances, prices, swaps and broadcasts leave through the built-in client, each blockchain gets its own circuit, and if Tor fails, Kyro stops.

The server sees •••.•••.•••.••• A Tor exit relay
  1. KyroYour computer
  2. 1Relay 1Sees your address, blind to the rest
  3. 2Relay 2Sees two other relays
  4. 3Relay 3Sees the request, never you
  5. NetworkSees a Tor exit

What servers see

Your IP stays out of the log

A wallet has to ask servers about your addresses. The question is whether your IP address comes with it.

A direct connection

203.0.113.42 balance bc1q…7f3a

203.0.113.42 balance 0x12…cdef

203.0.113.42 balance So1a…9xK2

  • Every server sees your IP address.
  • One IP asking about three addresses ties them to each other, and to you.
  • Your internet provider sees the hosts you reach.

Kyro over Tor

exit relay A balance bc1q…7f3a

exit relay B balance 0x12…cdef

exit relay C balance So1a…9xK2

  • Servers see the IP of a Tor exit relay, not yours.
  • Bitcoin, Ethereum and Solana never share a circuit, so the circuit does not link your lookups.
  • Your internet provider sees only that you use Tor.

Tor hides who is asking, not what is asked: the server you query still sees those addresses. Run your own node to avoid that.

Monero

Monero, done properly

A full Monero desktop wallet with no light-wallet server. The node sends blocks and your machine scans them, so your view key never leaves it.

  • Your addresses and keys are never sent to the node.
  • Tor hides your IP from it. Your own node or a .onion works too.
  • A 25-word seed restores the wallet in Monero GUI, Feather or Cake Wallet.

Transaction review

Every signature, decoded

The interface never gets the last word. The Rust core decodes the real transaction and a native system window shows it, drawn outside the web view. A compromised page cannot change what you read.

  • Amount, recipient, network and fee, as Rust read them.
  • Your password, then your click, for every signature.
  • Unusual transactions need a second, reinforced confirmation.
  • Address-poisoning alerts and clipboard checks before you send.

Open source

Read the code. All of it.

Kyro is an open source wallet under GPL-3.0-or-later: interface, Rust core and app shell, on GitHub.

  • Dependencies pinned to exact versions, with committed lockfiles.
  • cargo audit, cargo deny and pnpm audit in CI.
  • SHA256SUMS with every release, and signed automatic updates.
  • Every server Kyro contacts is listed in the repo.

Bit-for-bit reproducible builds are a goal, not a guarantee yet. The installers are not code-signed yet, so your system warns on first launch.

Questions

Short answers

Is Kyro Wallet free?

Yes. Kyro is free to download and use, and open source under GPL-3.0-or-later. Sending, receiving and staking cost only the network fee. Swaps carry a Kyro fee from 0.7%, and providers add their own costs, all built into the quote. Fee details.

Is Kyro custodial?

No. Kyro is non-custodial. Your keys are created and encrypted on your computer. There is no account and no server holding your funds, so nobody, including us, can freeze, move or recover them.

Which blockchains does Kyro support?

36 blockchains: Bitcoin, Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Cronos, Mantle, Sonic, Flare, Kaia, Gnosis, HyperEVM, Sei, Conflux, Solana, TRON, Cardano, XRP Ledger, Litecoin, Dogecoin, Bitcoin Cash, Dash, Stellar, NEAR, Sui, Monero, TON, Cosmos Hub, Polkadot, Aptos, Algorand, Kaspa and Zcash. Plus 220+ tokens on them. What works on each one.

Is there a mobile app?

No. Kyro is a desktop app only. An app in a mobile store using the Kyro name is not ours.

How much does a swap cost?

The Kyro fee depends on the value of the swap: 5% for $5 or less, down to 0.7% from $10,000, and 0.9% if the token price is unknown. It is already taken out of the amount you receive. The blockchain charges a separate network fee, which goes to the network. Providers charge their own costs as well: NEAR Intents takes an amount equal to Kyro’s fee on the routes it serves directly, so those swaps cost about double the Kyro rate. The quote you see already includes everything. Full fee table.

Can I stake with Kyro?

Yes. Earn lists 16 options: staking on Solana, Cardano, TRON, NEAR, Sui and Aptos, ETH liquid staking with Lido, and lending on Aave. Rates are estimates, never guaranteed. Kyro takes no fee on staking, and nothing here is financial advice. Options and risks.

Does Kyro support hardware wallets?

Yes: Ledger and Trezor, including Trezor Safe 7. Supported on Bitcoin, Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Cronos, Mantle, Sonic, Flare, Kaia, Gnosis, HyperEVM, Sei, Conflux, Solana, TRON, Cardano, XRP Ledger, Litecoin, Dogecoin, Bitcoin Cash, Dash, Stellar, NEAR, Sui, TON, Cosmos Hub, Aptos, Algorand and Zcash.

What happens if I lose my recovery phrase?

If you also lose your computer or password, your funds cannot be recovered. Kyro keeps no copy and cannot reset it. Write the phrase on paper, keep it offline, and never type it into a website.

Can I import a recovery phrase from another wallet?

Yes. Kyro accepts standard 12 and 24-word BIP39 recovery phrases.

Does Kyro use Tor?

Yes. Tor is built in and on by default, with a separate circuit per blockchain. If Tor fails, Kyro stops instead of connecting directly. You can also use your own servers.

Does Kyro collect any data?

No personal data. No account, no analytics, no identifiers. Once a week, Kyro anonymously downloads a tiny file from its GitHub release over Tor, so GitHub’s download counter can estimate how many wallets are active; you can turn it off in Settings, Privacy. Every server the app contacts is listed in NETWORK.md. This website sets no cookies; it only reads the public usage counters from GitHub.

Is Kyro open source? Has it been audited?

The full source is on GitHub under GPL-3.0-or-later. An internal security review has been done. No external audit has been published yet.

Windows says “Windows protected your PC”. What do I do?

That is SmartScreen: the installer is not code-signed yet. Verify the checksum, then click More info and Run anyway. The one-line install command checks the checksum for you and does not trigger this warning.

How can I support Kyro?

Kyro is free. Donations keep it going. You can also sponsor on GitHub.
