Roadmap

Where Kyro is going

Version 1.0.7 today. This page lists what has shipped and what is planned. There are no dates, because a wallet ships when it is checked.

Done and next

Shipped

  • 36 blockchains, one phrase

    Bitcoin, EVM networks, Solana, TRON, Cardano, Monero and more, with 220+ tokens.

  • Tor built in

    On by default, a circuit per blockchain family, no fallback to a direct connection.

  • Signed automatic updates

    Downloaded over Tor, verified against a pinned public key, applied at the next start.

  • Swaps across chains

    Several providers compared, with Monero, Kaspa, Algorand and NEAR both ways through Exolix since 1.0.6.

  • Earn

    16 options: Lido, Aave v3, and staking on Solana, Cardano, TRON, NEAR, Sui and Aptos.

  • Hardware wallets

    Ledger and Trezor, one-step Ledger connect, token sends on Solana, TRON, TON, Stellar, Sui, Aptos, Algorand and NEAR.

  • Staking from hardware wallets

    Solana and Cardano on Ledger and Trezor, NEAR on Ledger.

  • Several wallets

    More than one recovery phrase on a device, each with its own password, accounts and history.

  • Watch addresses

    Follow any public address or xpub with no key.

  • Alerts

    Price levels and funds received, as system notifications computed on your device.

  • Simulation before signing

    On swaps and Earn calls: what you send and receive, what you approve, and calls that would fail.

  • Fee choice, speed up and cancel

    Slow, Normal or Fast on Send, and pending Bitcoin, Litecoin or EVM sends can be sped up or cancelled.

  • One-click Windows installer

    A single branded window since 1.0.1, and one-line install on every system.

Next, in no fixed order

  • Polkadot staking

    The next Earn option.

  • Code signing

    So Windows and macOS stop warning on first launch. See the code signing policy.

  • winget

    Install and update with the Windows package manager.

  • More Ledger chains

    Polkadot, Kaspa and Zcash on Ledger, where the device apps make it possible.

  • Compact filters for Bitcoin

    A private way to read Bitcoin without an address server, once its dependencies pass review.

  • Reproducible builds

    Bit-for-bit reproducible builds are a goal, not yet a guarantee.

Not today

What Kyro will not rush

A few things cannot be done safely yet. They stay out until they can.

Polkadot on Ledger

The Ledger app needs a metadata proof with each transaction, which Kyro does not build yet.

Device authenticity

Kyro does not run Trezor’s authenticity check. Do that in Trezor Suite.

External audit

An internal review has been done. No independent audit has been published yet.
