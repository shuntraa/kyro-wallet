Guide

Connect a Ledger

One click reads every chain your Ledger supports. You approve each app on the device, and the keys never leave it.

2 min read

Before you start

  • Close Ledger Live: it holds the USB device.
  • Use a data cable, and unlock the Ledger.
  • Install the apps you want with Ledger Live, and keep them up to date.
  • On Linux, install Ledger’s udev rules first.

Connect

  1. On the welcome screen choose Use a Ledger / Trezor, or go to Settings › Devices › Add a device.
  2. Every chain the Ledger supports is ticked. Untick what you do not want.
  3. Click Connect.
  4. Approve “Open Bitcoin”, “Open Ethereum” and the others on the device as Kyro asks. If another app is open, Kyro closes it first.
  5. Read the result per chain: Added, Not installed, or Skipped.

“Not installed” means you can add that app in Ledger Live and connect again. If an app is too old, Kyro says to update it.

Check a receive address

Before you share an address, show it on the device and compare. Kyro compares it with the one it derives itself, and any difference is a blocking error. Treat the device screen as the truth.

Sign

  1. Start a send as usual.
  2. Read the decoded transaction in Kyro’s system window.
  3. Read it again on the Ledger and approve there.
  4. Kyro verifies the signature before it broadcasts.

Blind signing

Some transactions cannot be decoded by the device, which then shows raw data. A Ledger with blind signing off will refuse them, and Kyro names the setting to change. Solana tokens may need “Enable Blind signing in the Solana app settings”. TRON tokens may need “Allow data” or “Custom contracts”.

With blind signing, the device protects your keys but cannot show you what you approve. Keep it off until you need it.

Limits

  • On NEAR, TON and Cardano the Ledger account differs from the software account for the same phrase.
  • Token sends work on EVM chains, Solana and TRON. Elsewhere, native coins only.
  • Earn covers Lido and Aave. Staking is refused from a hardware account.
  • Not available on Ledger: Monero, Polkadot, Kaspa and Zcash.
