Install with one command

Paste the command for your system into PowerShell (Windows) or Terminal (macOS, Linux). It downloads the latest release from GitHub, checks its SHA-256 and installs it. A file fetched this way is not marked as downloaded from the internet, so Windows SmartScreen and macOS Gatekeeper do not block the first launch.

Windows · PowerShell

irm https://kyrowallet.com/install.ps1 | iex

macOS and Linux · Terminal

curl -fsSL https://kyrowallet.com/install.sh | sh

Downloads the latest release from GitHub, checks its SHA-256 against SHA256SUMS, then installs it. The scripts are open source: install.ps1 · install.sh (website/src).

On Windows the usual installer window opens. On macOS Kyro goes to Applications; on Linux to ~/.local/bin/kyro with a menu entry. No administrator password is asked by the script.

Downloaded the file in your browser?

The installers are not code-signed yet, so Windows and macOS show a warning the first time you open a file downloaded by a browser. Verify the checksum first, then:

Windows: “Windows protected your PC”

  1. Click More info.
  2. Check that the file name is Kyro-windows-x64-setup.exe.
  3. Click Run anyway.

macOS: “Kyro can’t be opened”

  1. Drag Kyro into Applications.
  2. Right-click Kyro in Applications and choose Open, then Open again.
  3. Or go to System Settings › Privacy & Security and click Open Anyway.

Linux

chmod +x Kyro-linux-x86_64.AppImage
./Kyro-linux-x86_64.AppImage
# or
sudo apt install ./Kyro-linux-amd64.deb

The AppImage needs FUSE 2: sudo apt install libfuse2t64 (Ubuntu 24.04 and later) or libfuse2 (older releases).

For a hardware wallet over USB on Linux, install the Ledger or Trezor udev rules.

Checksum

Verify your download

The install commands do this for you. If you downloaded a file yourself, download SHA256SUMS next to it, compute the SHA-256 of your file and compare it with the matching line. If they differ, delete the file and download it again.

Windows (PowerShell)

Get-FileHash .\Kyro-windows-x64-setup.exe -Algorithm SHA256

macOS (Terminal)

shasum -a 256 Kyro-macos.dmg

Linux

sha256sum -c SHA256SUMS --ignore-missing

Build it yourself

You need Rust, Node.js 22+, pnpm 11 and the Tauri prerequisites. See the README.

git clone https://github.com/shuntraa/kyro-wallet.git
cd kyro-wallet
pnpm install --frozen-lockfile
pnpm build
